课程 11：脉宽调制（PWM）模拟电压仿真
=======================================================================

本课程探讨脉宽调制（PWM）作为使用 Arduino 数字引脚模拟模拟电压方法的基本原理。以下是您将学习的内容的简要概述：

1. **理解 PWM** ：深入了解 PWM 的基础知识及其在从数字信号模拟模拟输出中的作用，这对于控制 LED 等设备的不同亮度至关重要。
2. **数字信号与模拟信号** ：对比数字输出的特性（要么全开，要么全关）与需要一系列输出的应用需求，以及 PWM 如何弥合这一差距。
3. **在 Arduino 上设置 PWM** ：学习在 Arduino 上设置 PWM 的具体方法，包括选择正确的引脚（标有波浪线的引脚）并在 IDE 中配置它们。
4. **PWM 实际应用** ：实施一个实践练习，使用 PWM 控制 LED 的亮度，说明随时间变化电压电平的概念。
5. **课后作业** ：通过尝试不同的 PWM 值来改变 LED 亮度，加深理解，巩固课程中学到的 PWM 实际应用。
