课程 6：使用 Arduino 创建二进制计数器
================================================

本课程将引导你完成使用 Arduino Uno R4 WiFi 和 Sunfounder Elite Explorer Kit 构建二进制计数器的有趣过程。以下是您将学习的内容的简要总结：

1. **设置和工具介绍** ：从基础开始，本课程介绍了项目所需的工具和设置，包括 Arduino Uno R4 WiFi 和 Sunfounder Elite Explorer Kit 的组件。
2. **基础回顾** ：复习基本概念，如打开和关闭 LED、使用电阻以及设置 Arduino 上的引脚模式。
3. **二进制计数** ：课程的核心部分，你将学习如何对 Arduino 进行编程，使其使用 LED 进行二进制计数，使二进制数这一抽象概念变得具体。
4. **代码实现** ：详细讲解如何编写和实现 Arduino 代码，以控制 LED 并使它们以二进制方式从 0 计数到 15。
5. **课后挑战** ：课程以一个课后作业结束，挑战你通过添加另一个 LED 来扩展二进制计数器，使系统能够以二进制方式计数到 31。
