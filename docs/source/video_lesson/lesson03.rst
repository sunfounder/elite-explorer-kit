课程 3：用 Arduino 控制 LED 闪烁
=========================================

本课程是一个教程系列的一部分，旨在通过使用 Arduino R4 WiFi 开发板帮助学习者像工程师一样思考。在本节中，Paul Mcarter 将引导您搭建和编程一个简单的 LED 电路，使其使用 Arduino 以 SOS 模式闪烁。本课程涵盖了先前教程的实际应用，并介绍了基本的电子概念，如使用面包板、管理电路原理图以及编程 Arduino 来控制硬件输出。以下是您将学习的内容：

1. **作业回顾** ：讲师回顾了一项涉及使用 Arduino 控制 LED 闪烁的课后作业，建立在早期课程中教授的概念之上。
2. **电路搭建** ：在面包板上构建 LED 和电阻电路的详细指导，包括如何正确地将这些元件连接到 Arduino 开发板。
3. **Arduino 编程** ：在 Arduino IDE 中进行逐步编码指导，以控制 LED。这包括写入数字输出，以及实现 ``pinMode`` 和 ``digitalWrite`` 函数。
4. **调试技巧** ：关于调试代码中常见错误（如拼写错误或引脚设置错误）的实用建议，并强调检查工作和理解错误信息的重要性。
5. **课后作业** ：为进一步练习，学习者需要创建一个包含四个同时闪烁的 LED 的电路，每个 LED 都需要通过 Arduino 进行独立控制。
