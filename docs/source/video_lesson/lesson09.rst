课程 9：使用串口打印到串口监视器
================================================================

本课程重点介绍使用串口将数据从 Arduino 传输到计算机屏幕，特别是通过串口监视器。以下是您将学习的内容的简要概述：

1. **串行通信简介** ：了解 Arduino 与台式计算机之间串行通信的基础知识。
2. **设置 Arduino 环境** ：配置 Arduino IDE，选择正确的开发板、端口和基本项目设置，确保一切就绪以进行串行通信。
3. **开发一个简单的计数程序** ：编写一个计数数字并使用串口在计算机屏幕上显示这些数字的程序。
4. **增强程序功能** ：结合各种数据类型和字符串操作，以有效地格式化并在串口监视器上呈现数据。
5. **课后作业** ：通过修改 LED 闪烁程序以包含串行通信，应用所学概念，通过实践应用巩固课程内容。
