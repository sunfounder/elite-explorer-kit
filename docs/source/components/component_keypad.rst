矩阵键盘
========================

矩阵键盘是一个由12或16个OFF-(ON)按钮组成的矩形阵列。
它们的触点通过一个排针引出，适合连接排线或插入印刷电路板。
在某些键盘中，每个按钮连接到排针上的单独触点，而所有按钮共享一个公共地。

.. image:: img/keypad314.png

更常见的是，按钮采用矩阵编码，这意味着每个按钮桥接了矩阵中一对独特的导线。
这种配置适用于微控制器的轮询，可编程为依次向四条水平导线中的每条发送输出脉冲。
在每次脉冲期间，它依次检查其余四条垂直导线，以确定哪一条（如果有）正在传输信号。
应在输入线上添加上拉或下拉电阻，以防止微控制器输入端在没有信号时出现不可预测的行为。
