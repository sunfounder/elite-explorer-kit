10軸IMUモジュール
============================

.. image:: img/10_axis.png
    :align: center
    :width: 40%

10軸IMUモジュールは、x、y、zの3軸にわたる加速度、角速度、磁場強度を測定できる高精度の10軸（10DOF）モジュールです。3つの主要センサー（SH3001、QMC6310、SPL06_001）で構成されており、I2Cプロトコルを介して通信します。

このモジュールは3つのセンサーに基づいています：

1. **SH3001**：これは6軸の加速度計およびジャイロスコープで、x、y、zの3軸で加速度と角速度を測定できます。
2. **QMC6310**：これは3軸のデジタルコンパスで、x、y、zの3軸で磁場の強さを測定できます。
3. **SPL06_001**：これは気圧と温度のバロメトリックセンサーで、大気圧と温度を測定できます。

SH3001はx、y、zの3軸で加速度と角速度を測定します。QMC6310はx、y、zの3軸で磁場の強さを測定します。SPL06_001は大気圧と温度を測定します。これらのセンサーからのデータは組み合わせられ、モジュールの空間における方向に関する正確な情報を提供します。

10軸IMUモジュールは、ドローン、ロボティクス、正確な方向情報が必要な他のプロジェクトなどのアプリケーションで一般的に使用されます。Arduinoボードと互換性があり、I2C通信プロトコルを使用して簡単にインターフェースできます。
